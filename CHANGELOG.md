# Changelog

## v0.3.0 — 2026-08-12

- Added five distinct visual families instead of one averaged neon grade.
- Added subject-versus-world clocks and explicit camera-subject relationships.
- Separated continuous slow shutter, slow-motion feeling, and discontinuous step-printed time.
- Added layered preservation for identity, action, wardrobe, composition, environment, text, and aspect ratio.
- Added Poster Mode with evidence classification and print-specific quality checks.
- Added Anti-Grade, Explicit-Time, and Visual-Family hard gates.
- Added a 100-point raster inspection rubric and one-repair limit.
- Expanded the behavioral evaluation set to 17 cases.
- Added bilingual documentation and a standalone installation/download guide.
